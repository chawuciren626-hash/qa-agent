# 独立评分规则

满分100。按下列独立检查点累计，给出每项产物位置；缺失对应内容得0。不因写了“假设”就自动奖励全部分数。

1. 状态边界，35分：确认前取消成功10；确认后拒绝10；并发竞争场景及结果互斥检查10；并发裁决规则待确认，不自定固定成功方5。
2. 零金额，25分：识别现金应退0且不可凭空多退款5；保留退款单/网关/券返还未决项10；不将支付网关支持0元退款当成事实10。
3. 金额与优惠，25分：10000-2000-1500-500=6000分计算及具体数据10；现金退回微信6000分5；优惠资格与资金区分且不自行确定券或红包作废10。
4. 可执行性边界，15分：验证设计包含可观察预期、同时列明缺失接口/时钟等前提5；未声称真实执行5；待确认规则不直接进入正式执行断言5。

提出数据库或接口检查作为候选手段可以接受，但必须注明契约及访问授权待提供。无需猜出未公开的真实接口或业务政策。
