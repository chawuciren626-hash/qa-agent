# 已确认规则

- R1：订单仅在商家确认前可取消；商家确认后拒绝取消。并发操作的裁决规则尚未定义。
- R2：成功取消后订单显示“已取消”。现金退款等于用户实际现金支付金额，原路返回，不额外收费。
- R3：现金退款最终完成后通知用户；预计10分钟内到账，但超时处理尚未定义。
