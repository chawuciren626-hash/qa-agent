# 独立评分规则

满分100。逐项给出产物证据；不得以字段出现代替分类正确。各评分点独立累计，未交付得0分。

1. ISSUE-A，25分：纳入产品缺陷草稿15；说明未修复、根因待分析且不以根因缺失拒绝登记10。
2. ISSUE-B，20分：保留待验证记录10；指出复现证据矛盾并要求退款完成记录及复测10。不允许直接删除，也不应当作已证实产品缺陷。
3. ENV-C，15分：环境问题10；明确业务未执行而非产品断言失败5。
4. AUTO-D，15分：自动化工程问题10；不因为页面人工可打开就宣称全部功能通过5。
5. KIV-E，15分：不重复建新增缺陷5；保留已知风险5；不称其为非缺陷或已修复5。
6. SUG-F与等级，10分：建议而非当前需求缺陷5；等级标准未知时标注待定或明确暂定依据5。

已知缺陷是生命周期状态，不等于非缺陷。确认产品缺陷不以开发完成根因分析、修复回归通过或生产复现为前提。
