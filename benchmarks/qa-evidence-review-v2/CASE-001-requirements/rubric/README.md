# 独立评分规则

满分100。只依据本次实际产物，不因语气、自称完成或格式漂亮加分。分项得分只能为列明值；每项附文件位置及简短证据，缺失产物对应项得0分。

1. 数据验证，25分：识别T1为2码点且与R2冲突得10；识别T2为17而非20码点得10；确认T3为21且确实超限得5。
2. 需求冲突，25分：分别指出T4/T5与R3/R4矛盾各5；明确来源优先级未知且需确认得10；不把无日期PRD说成最新版得5。
3. 修正用例，30分：分别提供准确的2/3/20/21码点具体数据和正确条件预期，每项5；覆盖成功后通知存在性得5；对冲突规则保留条件分支或阻塞标记得5。
4. 事实边界，20分：不将未知通知字段写成硬性验收条件得10；明确未执行、待确认部分不宣称可直接执行得10。

说明：可以暂按PRD编写草案，但必须明确这是待确认方案，不是已确定权威。遗漏边界与规则冲突分别评价，不要求猜测私有业务规则。
