# 通用验收需求 V1

本地虚构文档草稿管理系统，无真实账号或业务数据。每个 scope 隔离数据，reset 将该 scope 恢复为一条 Sample document、预算 120、状态 draft 的种子记录。

业务要求：
1. 列表展示标题、预算、状态。
2. 标题去首尾空格后长度为 1-40，空标题和超长标题不得保存。
3. 预算必须是非负整数，空值、小数、负数都不得保存。
4. 成功创建显示 Created，列表应真实出现新草稿。
5. 删除只影响当前 scope 中的目标记录，显示 Deleted。
6. 服务失败必须显示错误，不得虚报保存成功。

固定检查点：TC-BASE-01 种子列表；TC-BASE-02 正常新增；TC-BASE-03 空标题；TC-BASE-04 超长标题；TC-BASE-05 负数预算；TC-BASE-06 删除。

测试范围仅限 prepare 命令所登记的 127.0.0.1 验收地址。需求分析、测试点、用例仍需真实专业 Agent 产出并经确认；固定用例和参考脚本是基座回归资产，不代表模型生成能力已经通过。
