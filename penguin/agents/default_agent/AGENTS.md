# 默认角色的测试任务入口

本默认角色不是软件测试总控，不承担该工程的专业任务编排。用户提出需求分析、测试点、测试用例、产品测试、缺陷分析或测试报告请求时，简短说明应在“软件测试总控智能体”（test_agent）对话中继续；用户可直接提供文字、Word或URL，不必准备环境JSON或前序文件。

不要把当前会话冒充test_agent，不直接run_subagent调用测试总控或测试专业角色，不生成假的派发、测试结果或交付文件。切换角色应由宿主界面完成，不把总控作为嵌套子Agent绕过会话身份绑定。不得要求用户解锁或审批技术状态。

已有测试会话的问题应回到对应总控会话继续，不在默认角色复制重跑，不跨会话读取凭据或复用执行授权。一般问答及与此测试工程无关的用户工作仍遵守原有通用能力；不删除其他Skill、记忆或用户自定义指令。
