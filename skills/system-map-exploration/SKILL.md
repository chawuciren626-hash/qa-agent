# 系统地图探索 Skill

路径基准：`docs/`、`scripts/`、`config/` 按 `project-action.mjs catalog` 返回的 `runtime_context.engine_root` 解析。

## 安全纪律（强制）

- 只读爬取：导航、读取、无害填充；**不提交有副作用的表单**（下单/删除/保存/发送类一律跳过并记录"未探索：副作用表单"）。探索授权 ≠ 执行授权。
- 有界：入口页广度优先，预算（页数/深度/时长）以派发契约为准，默认 ≤80 页/轮；越界分支列入"未探索"。
- 只访问授权环境（base_url 及其同域）；重定向出域即停止并报告。
- 凭据只用环境配置的引用走 `login.captcha_chain`；验证码/MFA 等人工卡片；不猜测凭据，不把凭据写进任何产物。

## 三层取法

1. **静态解析**：路由、sitemap、导航结构先行，形成候选队列。
2. **结构巡检**：真实浏览器逐页快照（DOM/UIA），页面锚点候选（≥2 指纹）入清单；网络捕获合并出接口清单（方法/端点/参数/响应结构），与项目既有接口契约去重。
3. **视觉兜底**：仅当结构层无法定位时使用视觉 grounding；**命中必须反查结构锚点**，坐标只留在证据文件，不进地图条目。

## 输入

- 环境地址（含所属端）、登录方式与凭据引用、探索预算（页数/深度/时长上限）
- 派发列出的既有资产条目（接口契约/历史地图），用于合并与去重

## 工作步骤

1. 登录建立已认证会话（人工卡片等待如实上报）。
2. 静态解析生成候选队列；逐页结构巡检，逐页保存截图与网络记录作为证据。
3. 表单只做无害填充，记录"有副作用的表单未提交"清单。
4. 合并接口清单；为每个页面登记锚点候选（≥2 指纹）。
5. 汇总覆盖率声明：发现/走到/未探索（原因分类）。
6. 全部条目标 candidate，附证据路径与新鲜度（环境地址 + 探索时间）；不自行晋升 verified。

## 输出

- `maps/<env>/pages.json`：页面清单（路由/标题/模块/锚点候选/证据路径）
- `maps/<env>/apis.json`：接口清单（与既有契约合并去重）
- `maps/<env>/coverage.json`：覆盖率声明与未探索清单
- 建档报告（Markdown）：本次探索摘要、警告与材料局限

## 禁止事项

- 禁止提交有副作用的表单或执行任何写操作；禁止访问授权范围外的地址。
- 禁止把 candidate 标成 verified；禁止在地图条目存放坐标或凭据明文。
- 禁止跳过覆盖率声明；未探索的分支必须显式列出并说明原因。
