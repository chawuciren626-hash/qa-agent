# 回归选择与不稳定用例治理

返回[测试选择](../SKILL.md)。策略建议不替换现有Profile、预算或选择回执。

- 从变更模块及明确依赖向外判断影响，结合高风险业务和历史缺陷补回归；缺乏依赖映射时说明不确定范围，不声称精准影响分析。
- 历史耗时与失败必须来自可核验批次；估计值和实测值分开。短时预算不能静默遗漏必须覆盖的高风险项，应在选择结果/说明中展示超预算与未覆盖风险。
- 执行类型、模块、风险、数据影响分别保留，不把API、smoke、destructive挤成互斥单标签。
- 现有选择器只执行已实现的Profile规则；历史失败等尚未被选择器消费的信号作为复核建议，不伪称已自动影响排序。需要变更选集时走正式选择与计划入口。
- 不稳定率应说明样本、环境、版本和统计口径。连续5次通过仅表示这5次观察通过，不证明已稳定。
- 重试不是修复。产品缺陷或未知失败保持风险；如业务明确批准隔离，必须有负责人、依据、期限和未覆盖说明，skip/fixme不计为通过或已修复。
- 不直接采用上游retries=2、全并行或固定两分钟smoke目标；执行并发、预算、重跑均沿用本次计划和现有控制。
