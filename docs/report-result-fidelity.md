- 歧义、源哈希变化或证据关联不成立时，不猜测恢复；标为来源未唯一确认，继续部分交付，不新增用户技术审批。
- Word/PDF/HTML使用派生正文附加结果来源及说明表，原Markdown草稿不改写；Excel/HTML实际结果列显示导入、合成、模拟及受影响属性。模拟状态显示“通过（模拟）”等，HTML筛选兼容该标签。
- 缺少实际说明时统一写来源未提供，不再由passed状态补造“本批次断言通过”；表头改为结果记录快照，不默认宣称是本次实测。

## 边界

来源哈希证明引用一致，不证明内容真实、预期正确或执行充分。来源字段本身存在歧义时不自动修复业务语义；工具不补造缺失字段，不更改历史输入、不关闭缺陷，也不自动执行产品操作。

字段恢复仅在独立报告export_report中启用；生命周期报告仍使用现有质量度量流程，通用导出文案及模式标签适用于其结果展示。报告中的模型自由正文可能仍不准确，本轮不宣称已解决全部语义问题。

原始失败会话与产物保留，没有将旧文件修成通过。工程验证不等同真实Agent已自主复验，后者待本轮后续统一验收。
