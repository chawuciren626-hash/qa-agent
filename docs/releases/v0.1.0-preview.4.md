# AITestHarness 0.1.0-preview.4

Windows x64 预览版，内置 PenguinHarness 0.2.16、Node.js 24.14.0、Python 3.12.10 及 Playwright 浏览器。无需另外安装宿主或开发工具；模型服务账号和额度由用户提供。

## 本次内容

- 统一应用入口、宿主、工具运行时、数据和工作区布局。
- 固定宿主版本并通过兼容层构建，保留第三方许可证和声明。
- 首次模型配置、连接验证和示例任务引导；成功发起任务后隐藏，已有测试任务的用户自动跳过。
- 同宿主版本事务升级、安装失败恢复及卸载保留数据。
- 更新根目录 README，补充安装、目录、开发和升级说明。

## 下载和安装

下载 **AITestHarness-0.1.0-preview.4-win-x64.exe**，选择当前用户可写的安装目录。安装后使用 AITestHarness Preview 快捷方式或目录中的 AITestHarness.exe。首次使用配置自己的模型，连接验证可能产生少量费用。安装包不包含维护者凭据、历史会话或测试任务数据。

更新已有应用前先退出应用，再选择原安装目录。当前只支持宿主 0.2.16、数据版本 1 不变的应用更新；不支持跨宿主版本升级或降级，也不要用上游宿主安装器覆盖本应用。

## 验证与限制

本附件由 GitHub Actions 的 Windows installation candidate 工作流构建并通过安装验证。本机另有 52 项发布相关定向测试、载荷校验和宿主隔离适配检查通过。安装包对应的具体安装验证状态见 **acceptance.json**；未完成项目明确保留 pending。

这是预览版，不是完整验收的稳定版。干净 Windows、新安装环境真实模型任务、六阶段发行验收和跨宿主迁移仍待完成，`distribution_ready` 保持 false。远端 core 回归为 654 项通过、6 项失败，其中 5 项在上一轮远端基线也存在；另一项子任务冲突保护用例失败尚待分析。不能将定向检查通过理解为全套测试通过。自有安装器当前未签名。

当前需手动从 AITestHarness Releases 下载更新；尚未实现应用自动下载和安装闭环。仓库目前为私有，只有授权账号可访问本 Release。

## 文件校验

使用 `Get-FileHash .\AITestHarness-0.1.0-preview.4-win-x64.exe -Algorithm SHA256`，与附件 **SHA256SUMS.txt** 核对。其余附件为载荷清单、验收状态和第三方声明。
