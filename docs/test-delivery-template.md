# 通用测试交付模板

更新日期：2026-10-13。参考用户提供的保标API测试交付样式，仅提炼结构和展示方式，不复制业务数据、账号或结论。

## 使用方式

- 用例节点继续调用 export_test_cases，报告节点继续调用 export_report，不增加用户操作或审批节点。
- design/test_cases.xlsx 是设计版，统一未执行；JSON保留自动化字段和追溯关系。
- report/test_cases.xlsx 是执行版，按case_id关联当前结果、问题及证据，不覆盖设计版。
- report/test_report.html 提供正文、问题清单、搜索和结果筛选，可直接浏览器打开。分享时请一并提供同目录的Excel、Word及PDF，否则下载链接不可用。
- Markdown、Word、PDF继续保留，正文表格在转换时保留。

## 展示与内容

Excel使用“测试用例 / 问题清单”双工作表：第2行标题、第3行说明、第4行数量、第5行表头、第6行起数据；冻结D6、自动换行、筛选、交替底色、结果配色、横向打印及重复表头。列定义在config/test-delivery-template.json。

用例包含模块、优先级、前置条件、步骤与数据、预期、实际或未执行原因、状态、问题与证据。问题包含分类、复现、预期、实际、影响和建议。未知结果不视为通过，缺少说明明确标注，设计用例中附带的状态不当作执行证据。

报告依次包括结论摘要、范围与环境、核心业务流程、问题与证据、测试数据及清理、未覆盖范围与回归建议、交付清单。不展示密码和令牌；不编造测试观察和清理成功；区分产品问题、工程问题及待确认事项。

最终对话只保留完成内容、产物链接、真正需要用户决策的问题，不让用户处理内部技术审查。

## 本轮边界

本轮优化交付模板和导出器，不代表独立子Agent派发、URL直接探索和可选环境配置已实现。后续须单独验证这些入口，不能以模板回归代替真实Agent端到端测试。

不覆盖历史已完成运行，模板验证使用合成数据。结构检查不等于客户端打开及版式检查。超长Excel单元格仍受软件行高限制，完整内容保留在JSON及HTML中。
