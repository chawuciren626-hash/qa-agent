## 联合收口：任务内记忆一致性

AITestHarness 模式下，首次上下文使用的个人偏好与项目/工作区记忆索引写入本机用户数据区的任务快照；压缩、恢复、模型切换后的新上下文继续使用同一注入内容。校验所有者、工作区及内容哈希，另一个用户或被修改的快照会被拒绝。快照正文位于 Agent State 之外，避免随 Agent 导出；原快照查询仍只返回元数据。新任务读取新的偏好。定向核心测试 16 项通过、核心构建通过。

边界：按需读取的记忆主题文件仍是当前文件；任务上下文与压缩记录仍随任务推进更新。这不是全文件只读快照，也没有把任务观察自动提升为个人偏好或正式项目规则。
