# 总控工具接口

## 结构化请求

- 宿主对隔离QA工作区中的结构化命令处理缺失的CWD占位目录；真实存在的CWD目录和普通命令不改写。总控结构化命令不允许切换到其他工作目录。
- exec_command新增可选qa_request对象。总控同时提供完整动作对象与正常execute命令，守卫在权限、当前身份和路径检查后，以排他创建方式保存请求，再由原入口执行。不再必须先调用write_file。
- 已有请求内容相同可以复用，不同内容或重定向拒绝覆盖。文件名不能推导动作，缺少qa_request且文件不存在仍拒绝，绝不自动猜create_run等动作。
- 宿主在启动命令前再次比较实际请求文件与qa_request。钩子未准备文件、文件被改变或不是对应结构化命令时不启动，避免静默忽略新参数后执行旧文件。
- 放行单条ls -la对当前会话run阶段目录的只读元信息查看。禁止递归、通配符、Shell组合、其他会话和工程目录；不放行专业脚本或产品操作。
- 未升级宿主仍可使用原write_file、execute路径；专业子Agent继续使用原文件传输协议。总控说明按工具是否暴露qa_request选择入口。

这是请求准备与工具可用性修复，不是新的执行授权或恰好一次执行机制。请求已保存不代表动作执行成功；结果未知时仍须查回执，不能重放产品操作。守卫属于误操作防护，不是OS沙箱。

## 已有角色的接口同步

`scripts/sync-controller-tool-interface.mjs` 通过宿主配置 API 更新总控工具定义，默认只检查，`--apply` 执行同步。任务运行时拒绝同步；保留模型、其他工具和非工具配置，自定义参数冲突拒绝覆盖。更新宿主默认定义后，也需检查已有角色的持久化工具定义。

## 派发参数

`agent_id`、`prompt`、`description` 必填；角色和任务正文必须与登记值一致，展示描述可改写。`yield_time_ms` 仅接受 250 至 600000 毫秒的有限数值，不授予额外执行权限。其他参数按接口 Schema 拒绝，完整约束见[派发内容绑定](delegation-content-binding.md)。
