# 第5项断言范围与部分结果修复

日期：2026-10-20。范围：A5-04，以及独立执行到报告的部分结果保真。本批不增加审批节点，不修改原失败会话，不重放产品操作。

## 根因与修复

1. 原断言的expected是模型自由文字，可能包含工具没有检查的字段。新增checked_condition，由浏览器执行工具记录实际定位目标、条件、比较方式和值，沿用脱敏；保留原断言状态，不伪造补测。报告标明“预期（非验证结论）”，独立展示实际条件。源记录唯一匹配且哈希一致时才恢复这些字段；旧记录或来源不明不能继承模型编造的检查范围。
2. 独立执行正常finish不代表业务范围全部完成。finish新增可选untested字符串数组，不要求环境配置或前序用例。存在未测项、受阻或跳过记录等时交付partial；普通失败断言不自动变成未执行。coverage明确未测范围是执行角色声明，空数组和completed都不能证明全覆盖。
3. 报告索引原来主要标识异常恢复的partial，现覆盖正常finish的partial与未测清单。导出时保留哈希绑定源结果的partial和coverage，并自动将报告任务结果收口为partial，不把技术状态纠正转交用户。原通过/失败计数不变，未测范围不塞入通过数量。
4. 更新执行与报告角色、Playwright Skill、结构化入口说明及独立派发指令。标题匹配不证明预算或状态；错误反馈检查通过不代表创建成功；HTTP错误或断言失败本身不能确定产品缺陷，原因证据不足保留needs_review。
