# 第3项：统一目录上下文

本文保留该阶段的实现和验收记录。当前宿主适配已经接入，日常目录规则见[会话目录适配](penguin-session-workspaces.md)；新总控会话拒绝选择工程目录及其内部目录。下文底层接口兼容能力和“后续第4项”是当时记录，不是当前使用指引；最新进度见状态页（本地历史记录，不随源码分发）。

## 四类目录

- engine_root：共享程序目录，存放脚本、模板、配置和依赖。
- workspace_root：用户选择的工作空间，或后续配置的默认工作空间。
- session_root：该工作空间内的独立会话子目录。
- run_root：本会话的 output/runs，每个run有独立产物、清单和锁。

集中实现为 scripts/directory-context.mjs。未设置上下文时保留旧路径，不搬迁历史数据；显式上下文错误时拒绝执行，不静默退回工程根目录。

## 传递约定

基础接口为进程级 QA_DIRECTORY_CONTEXT JSON，包含 version=1、engine_root、workspace_root、session_root、session_id。路径必须绝对且不重定向；会话目录必须是工作空间的专用子目录，不得覆盖程序目录本身或其output/scripts/config/node_modules/skills/penguin目录。建议工作空间独立于程序；用户显式选择程序所在目录时，可创建独立时间戳子目录。子命令继承相同上下文。创建运行时记录目录身份，后续读取验证所有者。

同一进程不动态切换多会话环境变量；并发会话使用独立子进程环境，避免互相覆盖。第4项负责把本接口接到PenguinHarness会话创建、恢复和工具进程启动入口，不要求用户自己填写环境变量。

## 已接入

运行创建/读取/锁、结构化动作归档、控制状态与审计、父子身份/工作目录验证、阶段交接、产物校验、质量索引、最新结果索引、命令日志、执行尝试目录与执行授权快照、Word提取、报告和设计导出的运行路径已接入统一解析。

程序和依赖路径仍属于engine_root；执行授权快照同时记录共享程序和当前会话输入，不扩大到其他会话目录。导出器继续接收明确的运行内绝对文件路径，不在每个会话复制node_modules。数据路径越界与目录链接被拒绝。

个别历史项目专用的临时脚本（如run-retest、run-tms-tests、tmp-stats等）仍保留原状，不作为新会话通用入口使用。未自动整理、迁移或删除历史文件。
