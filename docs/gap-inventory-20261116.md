## 给 Codex 的建议顺序（按"演示主张"排）

方案 §20.3 定了三次演示各证一件事：①进得去 → 建档 10 秒出清单；②测得稳 → N=3 + 取证 diff；③测得准 → 种子集召回。当前缺口正好按这个顺序补：

1. **B1 + A1**（环境实体 + 建档第一屏）——最便宜、演示价值最高，工具现成，只差平台字段 + 一个向导步骤 + 报告展示。
2. **A5 + A6**（上下文装配 + 知识条款化）——治 token 与可追溯，是"这次重构的立论"在产品里的兑现。
3. **A3 + A4**（确认三层 UI + 报告审批流）——治"卡点太密被绕过"，算法都现成。
4. **A7**（能力画像标定）——在刚改完的模型设置上加档位与实测，改动面小。
5. **B3**（种子缺陷集）——与 M2 并行的人工工作，越早启动越早能回答"你到底有没有用"。
6. C 类按方案 M2/M3 节奏走，不要提前。
