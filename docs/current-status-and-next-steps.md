## 当前运行方式

用户通过 PenguinHarness 的总控 Agent 输入需求文本、文档或链接。总控先判断目标范围，再基于 `config/orchestration-workflow.json` 创建并执行本次运行计划。正式产物写入：

```text
output/runs/<run_id>/
  analysis/
  design/
  selection/
  execution/
  quality/
  defects/
  report/
```

分析、测试点、测试用例为产出后确认；真实自动化执行为执行前确认。缺陷与报告只处理真实结果和证据。
