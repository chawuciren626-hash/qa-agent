# 客户端 v2 界面改造

日期：2026-10-16。参考 `aitestharness-prototype-v2.html`。适配已核对的 PenguinHarness 0.2.13。

后续定时任务／资料库独立页面与侧栏三项展示改造，见 `client-sections-2026-10-16.md`；下文记录第一版改造与当时的安装结果。

## 实现

- 浅灰 280px 侧栏、白色主区域、统一圆角与边框；手机沿用宿主侧栏抽屉。
- 居中新建任务首页，功能测试／接口自动化／Web 自动化场景和五个快捷输入。
- 保留原生输入控件、中文输入法处理、Shift+Enter、图片粘贴、文件选择、模型、技能、审批模式及停止／追加消息流程。增加直接附件入口。
- 场景作为独立文字块传入首次请求；原话、技能指令、文件名和附件数据保持原有结构。
- 新建项目弹窗支持中文名称、空值／重名校验、多来源目录选择和移除。复用宿主目录浏览接口；每个任务选择一个工作文件夹，继续使用现有会话目录隔离。
- 项目任务树、最近任务、搜索、刷新、折叠、显示更多、选中状态，以及项目名称／任务名称和真实运行状态。
- 保留原生消息渲染、执行详情折叠、交付物卡片、HTML/PDF 预览及本机报告打开机制。
- 原管理页保持可达。定时任务入口指向当前测试智能体的定时任务配置；资料库入口指向其已有记忆资料页。未新增独立资料管理或调度服务。

## 数据与兼容范围

新增的“项目”是客户端的测试任务组织分组，不创建新的宿主智能体／模型配置空间。名称、来源目录和任务归属保存在本客户端 localStorage，按宿主安装标识、用户、配置空间隔离；重启保留，不提供跨浏览器／设备同步。历史原生工作空间以只读方式加入分组展示；其余历史功能通过“更多功能与历史项目”保留。

目录归属匹配要求完整路径边界；优先显式任务归属，其次采用唯一最长目录匹配，歧义不自动归属。未修改或搬迁历史会话、业务文件和模型配置。多个来源文件夹不会自动合并或赋予额外文件访问能力。

空闲状态不等于成功；只有明确本轮完成信息才显示“本轮已完成”。运行、等待确认、失败、连接异常、停止分别显示，新一轮用户消息不能沿用旧的成功标记。

## 文件与安装

- `penguin/ui/workspace-ui.mjs`：可维护的 React 组件和分组／状态逻辑。
- `penguin/ui/workspace-ui.css`：视觉样式、响应式布局。
- `scripts/client-ui-patches.mjs`：与已安装版本的组件连接点，逐项验证唯一锚点；不支持的版本拒绝覆盖。
- `scripts/install-penguin-runtime.mjs`：沿用统一校验、备份、事务更新、失败回退机制。交付展示与新界面编入同一个版本化模块；无需新增安装记录格式。
- `scripts/preview-client-ui.mjs`：仅绑定 127.0.0.1 的隔离工程预览，合成接口，不访问真实模型或会话数据库。

安装前检查：`node scripts/install-penguin-runtime.mjs "D:/Program Files/PenguinHarness/resources/app" --check`。
正常从托盘退出宿主后，执行同一命令的 `--apply` 并重新启动。安装器拒绝在宿主运行期间修改安装目录。
`--restore` 沿用原语义：恢复统一适配前的宿主文件，包含工作空间、交付、可靠性和界面适配，不是仅撤销这次样式。
