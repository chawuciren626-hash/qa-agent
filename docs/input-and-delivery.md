# 输入与交付约定

## 行为

- 外部文件不在允许的项目输入或当前会话附件目录时，返回request_attachment_once及简短附件导入提示。禁止对同一未导入来源继续换路径、Shell、扫描或转写绕过；此次回执retry_allowed=false只针对该材料，不停止整个控制会话。上传到当前会话后可继续原任务。
- 保留会话隔离、目录联接和越界保护。采用当前会话附件入口，不新增任意目录导入器，也不声明已支持文件夹批量导入。已有材料可继续处理，缺少关键材料才向用户提示一次；不要求技术解锁材料。
- CLI参数解析失败不再返回stop_and_request_review。无歧义父会话仍记录可纠正回执；缺少或重复父会话参数时给出命令纠正提示，不猜测会话身份、不执行动作。
- handoff已经提供一致状态时，下一步提示改为沿保存计划继续或交付，不再要求重复查询相同run_status。需要确认、展示异常和权限边界保持原逻辑。
- delivery.reply_template基于已完成产物合同和当前哈希生成摘要与真实链接，默认只含用户交付格式，不含内部JSON。总控沿用该模板，补充必要业务结论、限制和真正待决定事项，不重复播报completed/内部状态。

## 边界

完整工具证据保留。交付模板只辅助形成摘要与链接，不保证模型自由回复完全遵循模板；业务语义和文件打开体验须单独验收。

## 问题与局限展示

deliveryPresentation 从哈希校验通过的 task_result 读取 summary、questions、limitations，分别返回 pending_questions 与 limitations。仅在有待决问题时生成待确认小节；awaiting_confirmation 仍保留，不能跳过用户选定的确认节点。无有效任务文件时问题状态为 unknown，不推断为无问题。
