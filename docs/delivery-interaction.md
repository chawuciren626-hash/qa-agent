# 可点击交付与简洁对话

更新日期：2026-10-14。

## 对用户的变化

- 最终回复以业务结果、关键风险、交付链接为主；无待决事项就结束，不追加技术确认。
- 已有HTML/PDF等交付物通过工作区文件预览入口查看。Excel、Word和XMind卡片在桌面窗口可调用本机默认应用；未安装对应应用时明确报错，保留下载和“在文件夹中显示”。浏览器登录不是桌面授权，不能调用本机打开接口。
- 中间助手说明及工具/思考记录默认合并到“执行详情”。最终答复、人工事项、错误和审批仍可见；工具审批会展开所在分组。没有删除、重写会话轨迹。
- 只对测试总控会话启用新展示，不改变其他非测试Agent的界面。共享角色指令同时要求子Agent减少内部旁白。

## 工程实现

正式handoff在presentation.delivery提供经过文件存在性检查的链接。只发布已交付或等待业务确认阶段的实际可读非空文件，不把技术JSON当主要交付物。缺少导出不伪造链接；该辅助展示不批准任何业务结果。

链接使用工作区相对路径，兼容中文、空格和XMind。前端对当前会话执行文件检查，再调用原生onOpenFile进入文件面板。点击时重新查询存在性，不依赖旧缓存。文件不存在或应用打开失败只提示当前文件问题，不改变运行状态、不触发Agent重试业务操作。

HTML沿用宿主带sandbox的预览服务，未建立新的任意文件HTTP服务。新增open-deliverable接口复用当前会话鉴权、工作区路径解析，并仅接受output/runs下design/report中的xlsx/docx/xmind/pdf。OS启动前核对文档头，禁止exe、脚本、URL及工作区外路径；Windows路径经环境变量传递，不拼入命令文本。用户点击才触发本机应用打开。

## 安装与回退

统一安装器scripts/install-penguin-runtime.mjs同时管理工作区和交付补丁，支持已检查的PenguinHarness 0.2.13、0.2.16。0.2.16使用独立前端配方及新版hook/文件路由适配，见[升级记录](penguinharness-upgrade-2026-10-20.md)。安装前验证全部锚点、现状和原件SHA256；应用更新或未知修改时拒绝覆盖。旧install-penguin-workspace-adapter.mjs及install-penguin-delivery-ui.mjs入口均转到同一管理器，--restore会一起回退两项能力，不再单独拆层。

使用 --check 只读检查、--apply 安装/更新、--restore 回退两项补丁、--recover 恢复未完成的安装事务，首个参数为resources/app目录。安装修改前必须从托盘退出应用；安装器检查本机应用进程，拒绝运行中修改。不会强制关闭程序。服务端及外部运行模块更新需要重启，前端入口和模块均使用内容版本标识。

已有两层旧补丁在校验完整备份链后接管，保存qa-runtime-install.json和*.qa-runtime-original；旧记录保留作历史依据，不再作为独立写入入口。项目移动后从新工程路径执行--check/--apply重建两个后端import，不需要手工先拆交付补丁。升级宿主前先统一回退；新版本未经适配不得强行套用。

修改前写入qa-runtime-transaction.json，逐文件使用临时文件替换。普通写入失败自动恢复本次操作前的全部文件及记录；进程中断后--check报告recovery_required，维护者执行--recover。恢复只接受事务记录中的前/后哈希，遇到第三方修改拒绝覆盖。该能力只保护安装文件，不迁移或删除会话、测试产物，也不等于跨文件更新可在应用运行中安全进行。

本机打开默认最多等待10秒；超时返回504及明确提示，用户先检查桌面是否已打开文档，避免重复打开。仅尝试结束本次启动辅助进程，不结束文档应用或进程树，不自动重试。接口鉴权、文件类型及工作区限制不变。

## 验证范围

presentation:contracts覆盖链接与路径边界、阶段交付筛选、对话折叠、原生打开参数和接口权限，并回归独立任务实际导出及交接。

verify-delivery-ui.mjs使用安装版真实React/Markdown/消息组件、合成对话和已有会话的真实报告文件，验证桌面1440x1000与手机390x844布局、折叠展开、HTML预览、PDF入口、浏览器拒绝本机打开、文件缺失反馈。不会提交用户消息或重跑产品业务测试。此检查不是新一轮真实模型对话，也不能把模拟接口响应当成本机WPS已打开的证据。

历史正文不重新生成；原有反引号包裹路径也可识别为文件卡片，但完全未标记的任意文本路径不自动猜测。后续新交付使用规范链接。历史报告内容、测试结果和原有失败记录保持不变。
