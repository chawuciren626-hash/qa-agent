## 修改

1. `browser-sequence.mjs`：CSS 目标格式移入 validateSequence，结构化入口将其归类为执行前输入纠错，不启动执行命令、不停止控制器。
2. sequence 的观察缺失、过期和未观察目标返回 invalid_operation、operation_started=false；不创建批次回执、不执行步骤，允许观察后纠正。已经开始的批次仍保留逐步回执，禁止整批重放。
3. `stage-evidence.mjs` / `child-command-policy.mjs`：对工具证明已经关闭/恢复、产物契约通过、outcome=partial 的浏览器交付，核验失败回执及命令的 run、父子会话、tool_call_id、时间、退出与终止证明，再允许将故障作为部分交付证据保留。非浏览器命令、取消/未知终止、伪造回执、修改产物不适用。
4. 已有 blocked 执行阶段可通过同一个 handoff 入口补做部分结果交接；必须核实原子会话和完整证据。追加 partial_delivery_reconciliation 和原阶段快照，保留原 blocked 事件，不直接编辑清单或清除失败。
5. 工程 docs 的读取纠错要求确切原路径、后续成功 native read 和同阶段成功校验，不靠模型文字声称已修复。
