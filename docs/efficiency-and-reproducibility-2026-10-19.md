## 4B 实现范围

| 项目 | 实现 | 边界 |
| --- | --- | --- |
| 子Agent单次入口 | exec_command.qa_request携带完整对象，由专业hook落盘后进入原execute | 原派发/授权/阶段/审计不变；旧文件入口兼容；已存在不同请求不覆盖 |
| 参数单源 | 浏览器操作允许字段在browserOperationFields集中维护，验证和catalog共同消费 | 语义约束保留专用验证，尚非所有动作的完整JSON Schema替换 |
| 原话引用 | source_message_key引用input_context中的真实用户消息键，程序恢复原文 | 不自动授予权限；目标、范围、设计及后续撤回仍按原规则核验；source_text兼容 |
| sequence | 2至4步；fill/select/check/assert，最多最后一步click/press并带断言 | 仅本派发完整快照已观察可见CSS目标；导航版本改变拒绝；逐步保存、检查绑定及取消，失败/未知停止 |
| 重试 | 保存批次结果和每步独立回执；重复批次只读结果 | 中断批次不自动续跑、不回滚、不整体重放；需根据已有事实决定后续 |
| 网络记录 | 每事件追加JSONL；兼容JSON窗口每32事件或操作结束刷新 | 最近500条窗口，日志最多10000条，序号/截断/写入异常明确记录；不是无限保留 |
| 按需快照 | version/sha256/page_epoch；if_sha256匹配时返回unchanged及基线hash | 仍读取当前页面，不缓存就绪或权限；无基线必须取完整快照，导航版本不同不复用 |
| 资源缓存 | 编译Schema按内容hash缓存，源变更立即重编译，最多32项 | 仅工程资源，不缓存业务来源、授权、设计结果或执行判定 |

失败证据、结构化断言和瞬时反馈仍按原规则记录；本批未启用“通过项截图采样”，避免以提速损失已验收证据。缓存只限进程内Schema编译，没有建设跨任务业务结果缓存或脚本回放器。

已确认工程调用数：单个支持动作从write_file+exec两次降为一次exec；批次不需模型逐步往返，但每步仍核验和保存。未测真实模型采用率，不承诺耗时降低比例。

## 依赖告警决策

升级前npm audit --omit=dev检出xlsx高危2条公告及xmind间接uuid公告。SheetJS升级后高危项消除。

尝试将xmind的uuid覆盖到11.1.1时，审计虽为0，但XMind实际导出失败：旧SDK调用uuid/v4，新版不再导出该子路径。已撤回这一不兼容覆盖，保留xmind 2.2.33与锁定的uuid 3.4.0，XMind结构回归恢复通过。不得通过npm audit fix --force降级整个SDK。

当前仍有2个中危依赖节点告警（uuid及受影响的xmind），并非两个已确认可利用路径。已检查SDK核心base/theme的调用为v4，公告涉及带buffer的v3/v5/v6；这缩小当前使用面的风险，不等于库已修复或全部路径安全。后续替换/升级SDK需同时验证结构、层级、中文及原生客户端打开；此项列为4C剩余风险，不隐去告警。
