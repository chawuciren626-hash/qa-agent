# Agent 开发与 AI 测试学习路线

更新日期：2026-09-30。面向有传统测试工作经验、编程和 AI 工程经验较少的学习者。

本套资料独立于当前测试智能体的开发进度：学习文档和离线练习不会启动 PenguinHarness、调用模型、执行业务测试或修改现有运行配置。文中的文档生成项目、数据和门槛均为教学示例，不代表公司真实系统的规则或行业标准。

## 1. 学习后应能做什么

最终目标不是记住名词，而是独立完成以下工作：

1. 读懂一个 Agent 的输入、上下文、工具、状态、记忆和输出链路。
2. 开发一个有明确停止条件、失败处理和可追溯记录的小型 Agent。
3. 为文档编写 Agent 建立可重复的评测集，并解释每个指标的含义和局限。
4. 从日志定位问题来自资料、检索、上下文装配、模型、工具还是导出。
5. 用可复核数据比较两个版本，而非只凭一次演示判断好坏。

## 3. 两条职业路线如何分配精力

你目前适合共同基础约占一半，Agent 测试实践约占三成，Agent 开发实践约占两成；这只是工作学习安排建议。

- Agent 开发路线：优先深化第 2、3、4 章，补足服务端、数据库、部署和调试能力。
- AI 测试路线：优先深化第 3、5、6 章，同时掌握第 4 章的执行机制，避免只能从最终文本猜原因。
- 共同要求：能自己检查输入数据、跑脚本、读调用日志、解释评价标准，并复现一次失败。

## 4. 全程贯穿的例子

教学产品：用户选择项目 A，Agent 从业务工具取得项目资料，按模板 V2 生成项目说明材料。它应核实名称、金额、日期与章节要求；缺失信息应澄清；未经批准不得提交正式版本。

教学资料：项目 A 的预算为 120 万元，截止日期为 2026-10-15；模板 V2 必须包含“项目概况、预算、实施计划”。旧模板 V1、其他项目和冲突资料用于构造干扰输入。它们不对应真实客户。

## 5. 学习所需环境

前几章只需要 Markdown 阅读器、Git 和本地 Python 3.10+。离线评测例子只用标准库：

```powershell
python docs/learning/examples/evaluate_metrics.py
```

后续开发实战才需要授权的模型 API、开发专用工具服务和依赖环境。先核验已有环境，安装作为单独的开发环境准备操作；不要将依赖安装写入正常 Agent 测试流程。模型 Key 放入本地环境变量或秘密管理工具，不写入练习、日志或 Git。

本资料不绑定特定模型供应商、Agent 框架或评测库。具体 SDK 参数、上下文上限、计费和指标实现以使用时的官方版本文档为准。
