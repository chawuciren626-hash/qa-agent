确认卡点 原型 · 等确认后落真实代码

本批：登录模块改版 —— 27 条确认项（需求 4 / 测试点 6 / 用例 17）。三层规则按方案原文逐条落成可计算状态，右下角审批条与硬闸联动。

1差异聚焦

只强制审「与上一版不同」的部分；未变的默认继承。没有上一版时全部按新增审，不假装能继承。

2抽样审核

每批随机 10% 深审，其余过。抽样用确定性伪随机（seed + id 哈希），同一种子抽出的名单可复现、可审计。

3风险加权

P0 / 涉资字段 / 权限变更 → 强制全审；P2 → 仅抽样。风险强制项不受 1、2 省略；未标风险的按强制全审处理。
